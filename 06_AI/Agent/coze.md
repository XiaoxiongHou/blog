# 概述

字节跳动推出的一站式AI智能体开发平台。

- 国内版：集成字节自研大模型（豆包、云雀、deepseek），适配中文场景（20种方言识别、繁体中文处理）
- 国际版：支持GPT-4o、Gemini Pro等国际模型

# 工作原理

## 六大层次

- 前端交互层：基于React+TypeScript构建可视化操作界面，提供拖拽式流程编排、组件面板和实时调试功能
- 核心引擎层：平台的“计算中枢”，包含应用解析器、LLM调度器、工具链执行器和对话状态管理器
  - 应用解析器：将可视化流程转换为可执行逻辑。
  - LLM调度器：平台接入大量模型，调度器根据问题复杂度来调度agent使用哪个模型及模型负载均衡/降级策略等。
  - 工具链执行器：负责调用工具（数据库/爬虫/api），数据格式转换，重试，权限校验和调用频率控制等。
  - 对话状态管理器：管理agent对话状态。多轮对话的上下文内容/大小/持久化等。
- 知识库与数据层：提供向量数据库、应用配置存储和数据处理工具，支持RAG场景和个性化服务
- 扩展与集成层：通过插件市场、API网关和第三方服务连接器实现功能扩展
- 部署与分发层：支持多端部署（网页/小程序/API）、版本管理和监控运维
- 安全与权限层：包含身份认证、RBAC权限控制和数据加密机制

## 工作流

应用定义 - 解析与编译 - 执行与调度 - 部署与监控

1. 开发者设计智能体人设/技能模块/对话流程
2. 平台解析执行逻辑/生成节点依赖关系图和数据流转规则/验证流程合法性
3. 调度LLM/调用工具链/对话管理
4. 一键发布多渠道（微信/抖音/网页）/监控性能指标/根据反馈自优化模型参数

## 关键技术

### 模块化插件架构
- 采用标准插件接口，支持热插拔
- 内置60+官方插件（新闻、天气、文档处理等）
- 自定义插件开发框架支持JavaScript/TypeScript代码嵌入

### 可视化工作流引擎
- 基于节点的编程模型，支持分支、循环和并行执行
- 实时调试功能：查看节点输入输出和执行日志
- 版本控制：支持工作流历史版本回溯和对比

### 多模型适配能力
- 国内版支持DeepSeek、豆包、Kimi等模型
- 海外版支持GPT-4o、Claude-3.5等模型
- 模型能力抽象层：统一API封装不同模型特性

### 知识库增强机制
- 支持多格式文档导入（PDF/Word/网页）
- 向量数据库实现高效相似度检索
- 自动文本分段和嵌入向量生成

# 核心功能

低代码开发：可视化工作流，拖拽式节点编排（开发周期缩短 80%），模板市场提供预制模板

插件与知识库：内置60+插件，支持自定义插件；上传多格式数据构建知识库（准确率提升 18%）

多模型与多模态交互：支持豆包、GPT-4o等模型，自然语言解析多模态指令

全场景部署与协作：一键发布至微信/飞书等平台，团队协作与数据加密
