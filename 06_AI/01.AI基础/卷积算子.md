卷积神经网络是视觉分类、检测、分割等深度学习任务的基础网络结构，它由输入层、隐层、输出层组成，其中包含多种类型的网络层，如：通用的卷积层、池化层、激活层、归一化层等。经过这些层的组合与连接，进而可以得到各种类型的卷积神经网络模块。相较于传统机器学习算法，卷积神经网络具有更强大的处理能力和分析能力。

卷积算子（卷积层）是卷积神经网络中最为基础同时又是最重要的组成部分，卷积算子是卷积神经网络中使用最为频繁的算子之一。卷积操作最早应用于信号处理领域，后来被广泛应用于图像滤波、图像去噪等领域，然而在卷积神经网络中卷积算子出现了各种变种和应用，发挥出更加重要的作用。

卷积中几个重要的参数是：步长（Stride）、填充（Padding）、卷积核（Kernel），

步长：滑动卷积核时，一般会从输入的左上角开始，每次往右滑动n列或者往下滑动m行逐一计算输出，将每次滑动的行数和列数称为步长。

填充：因为边缘上的像素永远不会位于卷积核中心，而卷积核也没法扩展到边缘区域以外，输入图像与卷积核进行卷积后的结果中损失了部分值，为了弥补信息损失，在进行卷积操作前，对输入进行边界填充（Padding），也就是在输入矩阵的边界上填充一些值，以增加矩阵的大小，通常都用“0”来填充。

# 题目分析

## 题目理解

卷积算子计算方法是从输出入手，每一个输出点都是卷积核和原始输入矩阵中的一块数据进行乘加操作（先逐点相乘，再加和）得到。

在计算之前需要明确输出矩阵的形状，对输出矩阵形状进行遍历，逐点计算输出即可。输出矩阵的大小符合计算公式：

Output size = (input size + 2 \* padding size – kernel size)/stride + 1

## 解题思路

* 根据padding参数对输入数据进行padding操作
* 根据题目所给参数（原始输入size、padding size、kernel size）计算卷积输出矩阵形状
* 循环遍历输出矩阵中每一个元素进行计算，计算时需要根据输出点来反向计算出本次卷积计算所对应的输入矩阵数据块；得到数据块之后，和卷积核进行逐元素相乘后再做加和；遍历完成后即得到输出结果。

```python
import numpy as np


def ParseInput():
    [channel, row, col] = list(map(int, input().strip().split()))
    # 注意是一行录入全部数据!!!
    signal = np.array(list(map(int, input().strip().split()))).reshape((channel, row, col))
    stride = int(input().strip())
    [channel, row, col] = list(map(int, input().strip().split()))
    kernel = np.array(list(map(int, input().strip().split()))).reshape((channel, row, col))
    padding = int(input().strip())
    paddingMode = 0
    if padding:
        paddingMode = int(input().strip())
    return signal, kernel, stride, padding, paddingMode


def Padding(signal, padding, paddingMode):
    if not padding:
        return signal
    mode = 'edge' if paddingMode else 'constant'
    return np.pad(signal, ((0, 0), (padding, padding), (padding, padding)), mode=mode)


def Convolution(signal, kernel, i, j, stride):
    krow, kcol = len(kernel), len(kernel[0])
    startRow, endRow = i * stride, i * stride + krow
    startCol, endCol = j * stride, j * stride + kcol
    region = signal[startRow: endRow, startCol: endCol]
    result = 0
    for x in range(krow):
        for y in range(kcol):
            result += region[x][y] * kernel[x][y]
    return result


if __name__ == '__main__':
    signal, kernel, stride, padding, paddingMode = ParseInput()
    channel, row, col = len(signal), len(signal[0]), len(signal[0][0])
    krow, kcol = len(kernel[0]), len(kernel[0][0]) # 注意第一维是channel!!!
    signal = Padding(signal, padding, paddingMode)
    outRow = (row + 2 * padding - krow) // stride + 1
    outCol = (col + 2 * padding - kcol) // stride + 1
    out = np.zeros((outRow, outCol), int) # 注意类型int!!!
    for i in range(outRow):
        for j in range(outCol):
            for c in range(channel):
                out[i][j] += Convolution(signal[c], kernel[c], i, j, stride)
    out = out.reshape(outRow * outCol)
    print(' '.join([str(x) for x in out]))


```
