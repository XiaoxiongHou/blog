没错，它是某个一次函数的图像，表达式是：

$$
y =  ax + b
$$

其中，$a$是斜率，$b$是截距。这个就是我们的模型！

考虑到后文表达的方便，我们采用如下形式的表达式：

$$
y = \theta_{0} + \theta_{1}x
$$

为什么用$\theta$加编号的形式？而不是$a、b、c、d....$的字母？因为随着机器学习模型复杂度的增加，参数也会越来越多，$a、b、c、d....$的符号很快就会用完。

现在我们假设 $\theta_{0} = 1, \theta_{1} = 2$，代入上面的公式就是：

$$
y = 1 + 2x
$$

然后我们计算一下$x = 100$时$y$的值：

$$
y = 1 + 2x  = 1 + 2 \times 100 = 201
$$

但我们观察上面的图像，广告费是100的时候，点击量应该至少大于300了。

这说明，我们刚才确定的参数 $\theta_{0} = 1, \theta_{1} = 2$完全不对，接下来，我们就要使用机器学习来求出正确的 $\theta_{0}$和$ \theta_{1}$的值。

在开始求解之前，我们先把上面的表达式改成：

$$
f_\theta(x) = \theta_0 + \theta_1x
$$

这样写的好处是，它可以清晰表达：这是一个含有参数$\theta$，并且变量是$x$的函数。

# 4 先看代码

废话少说，我们先看代码，建议你先执行一下：

```python
# ps_xa_cmc/software/ai/linear-regression/04_linear_regression.py

import numpy as np
import matplotlib.pyplot as plt

# 支持中文字体
plt.rcParams['font.family'] = 'SimHei'
plt.rc('axes', unicode_minus=False)

# 随机两个参数值
theta0 = np.random.rand()
theta1 = np.random.rand()


# 我们要预测的函数
def f(x):
    return theta0 + theta1 * x


# 目标函数
def E(x, y):
    return 0.5 * np.sum((y - f(x)) ** 2)


# 读取训练数据
train = np.loadtxt('click.csv', delimiter=',', skiprows=1)
trainX = train[:, 0] # 第0列是广告费
trainY = train[:, 1] # 第1列是点击量

# 标准化
mu = trainX.mean()
sigma = trainX.std()


def standardize(x):
    return (x - mu) / sigma


trainZ = standardize(trainX)

# 几个关键参数
ETA = 1e-3 # 学习率
diff = 1 # 误差的差值
count = 0 # 更新次数
error = E(trainZ, trainY) # 误差

# 重复进行参数更新，直到误差小于0.01为止
while diff > 1e-2:
    tmpTheta0 = theta0 - ETA * np.sum(f(trainZ) - trainY)
    tmpTheta1 = theta1 - ETA * np.sum((f(trainZ) - trainY) * trainZ)

    # 参数更新后，计算误差
    theta0 = tmpTheta0
    theta1 = tmpTheta1
    currentError = E(trainZ, trainY)

    # 与上次计算结果比较
    diff = error - currentError
    error = currentError # 保存本次结果，下次计算需要与此做比较

    # 日志
    count += 1
    print('第{}次：theta0 = {:.3f}, theta1 = {:.3f}, 差值 = {:.4f}'.format(count, theta0, theta1, diff))



# 绘图确认结果
plt.plot(trainZ, trainY, 'o') # 原始的数据

# 使用我们预测出来的函数绘图
x = np.linspace(-3, 3, 100)
plt.plot(x, f(x))
plt.xlabel("广告费")
plt.ylabel("点击量")
plt.show()

```

# 5 盲猜一下

回到我们上面定义的模型：

$$
f_\theta(x) = \theta_0 + \theta_1x
$$

我们现在的任务是得到$\theta_0$和$\theta_1$的值，那我们先盲猜一下怎么样？比如我们猜：$\theta_0 = 1, \theta_1 = 2$

然后拿几个数据看看效果：

| 广告费 | 实际点击量 | $\theta_0 = 1, \theta_1 = 2$时得到的点击量 | `误差` |
| ------ | ---------- | ------------------------------------------ | ------ |
| 58     | 374        | 117                                        | `257`  |
| 70     | 385        | 141                                        | `244`  |
| 81     | 375        | 163                                        | `212`  |
| 84     | 401        | 169                                        | `232`  |

误差有点大，我们期望的理想情况是，表格的最后一列数据为0，或者接近0。但要求每一个误差都达到这个水平是比较难的，特别是训练数据如果存在噪声（严重偏离线性函数的数据），就更加不可能了。所以实际实现时，我们一般追求的是`误差的和最小`。

# 6 目标函数

先来一点数学的震撼：

$$
E(\theta) = \frac{1}{2}\Sigma_{i=1}^n(y^i - f_\theta(x^i))^2
$$

不要慌，看完本文，你会理解的。注意，上面公式内的$x^i和y^i$不是$x或y的i$次方，而是第$i$个训练数据的意思。

这个函数被称为`目标函数`，其中的$\Sigma$是求和符号。我们拿上面的表格做一个对照，你就能明白上面公式的含义了：

|序号（$i$）| 广告费（$x^i$） | 实际点击量($y^i$) | $\theta_0 = 1, \theta_1 = 2$时得到的点击量($f_\theta(x^i)$) | `误差的平方`（$(y^i - f_\theta(x^i))^2$） |
|----| ------ | ---------- | ------------------------------------------ | ------ |
|1| 58     | 374        | 117                                        | `257*257`  |
|2| 70     | 385        | 141                                        | `244*244`  |
|3| 81     | 375        | 163                                        | `212*212`  |
|4| 84     | 401        | 169                                        | `232*232`  |

这里我们把最后一列改成了`误差的平方`，为什么？因为误差很可能是负数，负数和正数的复合运算比较麻烦。那为什么不用绝对值呢？因为之后要对目标函数进行微分，比起绝对值，平方的微分更加简单。

把上表最后一列的数据相加再除以2就是目标函数的最终取值，我们的目标就是让这个值尽量地小。

关于这个公式的最后一个问题：为什么要除以2？

这个也与后续的微分运算有关，是为了让微分后的表达式更加简单。因为我们是要让目标函数的取值尽量小，而由于目标函数一定是正数（平方和），因此乘以一个正数不影响关于最小的比较。

# 7 微分

让我们先停下来补一补数学，回忆一下什么是微分。

假设你开车上街，行驶时间跟行驶距离的关系如下图：


汽车在40s的时间里大约行驶了120m，那么速度是：$\frac{120m}{40s} = 3 m/s$。但这是平均速度，如果我想知道汽车在`第10s的瞬时速度`是多少怎么办？

我们假设上面图像对应的函数是$f(x)$，然后在10s附近取一个很小的变化量，比如0.1s，那么从10s~10.1s的平均速度是：

$$
\frac{f(10 + 0.1)}{f(10)}
$$

这个速度虽然代表的是10s~10.1s的平均速度，但直观感知，它与第10s的瞬时速度已经很接近了。如果变化量是0.01s，那么10s ~ 10.01s的平均速度就更加接近真实的瞬时速度了。所以只要我们取的变化量足够小（趋近于0），那它就是真实的瞬时速度：

$$
V_{x} = \lim_{h \rightarrow 0} \frac{f(x+h)}{f(x)}
$$

上面的公式表示第$x$s的瞬时速度。我们使用了一个变量$h$，在它趋近于0的情况下，得到的平均速度就是第$x$s的瞬时速度。

数学上把这个叫做微分，记做：

$$
\frac{d}{dx}f(x) = \lim_{h \rightarrow 0} \frac{f(x+h)}{f(x)}
$$

几个常见函数的微分和计算公式（如何从上面的极限公式推导出下面的微分公式，需要做数学证明，有兴趣的回去翻一下微积分教材吧）：

$$
\frac{d}{dx}x^n = n x^{(n -1)}
$$

$$
\frac{d}{dx}(f(x) + g(x)) = \frac{d}{dx}f(x) + \frac{d}{dx}g(x)
$$

与x无关的常数微分为0：

$$
\frac{d}{dx}a = 0
$$

多项式微分：

$$
\frac{d}{dx}\Sigma_{i=0}^n x^i = \Sigma_{i=0}^n\frac{d}{dx}x^i
$$

# 8 梯度下降法

回到我们的主题，我们现在的目标是找到合适的$\theta$值让我们的目标函数取值尽量地小：

$$
E(\theta) = \frac{1}{2}\Sigma_{i=1}^n(y^i - f_\theta(x^i))^2
$$

请注意，我们其实是有两个$\theta$的：

$$
f_\theta(x) = \theta_0 + \theta_1x
$$

上面我们尝试盲猜了一下（$\theta_0 = 1, \theta_1 = 2$），结果偏差非常大，也就是目标函数的取值非常大。怎么办？换两个数字继续猜吗？

这个时候你需要`最速下降法`。我们先开启上帝视角，假设我们已经知道了目标函数是：

$$
g(\theta) = (\theta - 1) ^ 2
$$

这个函数图像是：

想象抓住一根绳子两端，让中间自然下垂，中间最低点是坐标0，1

这里为了方便讨论，我们做了简化处理，自变量由两个$\theta$变成了一个。

哎哎哎，等一等，$x$去哪了？$y$又去哪了？

再仔细看一眼我们的目标函数：

$$
E(\theta) = \frac{1}{2}\Sigma_{i=1}^n(y^i - f_\theta(x^i))^2
$$

它的自变量是$\theta$，$x和y$对目标函数来说都是常量，在训练过程中，会被直接赋值（用训练数据）

回到我们的示例，我们通过观察图像很容易知道当$\theta=1$的时候函数取值最小。但是请注意，当你说出这句话（当$\theta=1$的时候函数取值最小）的时候，你的大脑已经经过了复杂的运算：大脑通知眼睛观察图像，眼睛看到最低点以后会看一下横坐标（大概是1）。但计算机面对的是数字，它没有大脑那么聪明，需要我们对它进行训练。

好了，铺垫这么多，下面我们开始解释`最速下降法`的原理：

首先对函数进行微分运算：

$g(\theta) = (\theta - 1)^2 = \theta^2 - 2\theta + 1$

$\frac{d}{d\theta}g(\theta) = 2\theta-2$

然后我们得到一个增减表：

|$\theta$取值|$\frac{d}{d\theta}g(\theta)$的符号|$g(\theta)$的增减|解释|
|---------|---------|--------|--------|
| $\theta < 1$ | - | 递减|当$\theta < 1$的时候，$\theta$越大，$g(\theta)$越小|
| $\theta = 1$ | 0 ||
| $\theta >1$|+|递增|当$\theta > 1$的时候，$\theta$越大，$g(\theta)$越大|

请始终记住我们的目的：我们想知道当$\theta$取值是多少的时候，$g(\theta)$最小。假设我们训练过程中随机取了一个值：$\theta = 3$，对照一下上面的增减表，我们知道微分$\frac{d}{d\theta}g(\theta) = 2\theta-2$的符号是正的（2*3-2 = 4），所以这个时候，我们应该减小$\theta$的取值，比如-1，这个时候微分的符号又变成负的了（2 * -1 - 2 = -4）。再看一眼增减表，这个时候我们应该增加$\theta$的值了。

那么问题来了，我们应该以什么粒度增减$\theta$的值呢？假如我们按照上述示例，取变化量为4，那么我们将会始终在3和-1之间振荡：

|$\theta$的值|微分符号|应该如何调整$\theta$的值|
|-------|----------|---------|
|3|+|减小4|
|-1|-|增加4|
|3|+|减小4|
|-1|-|增加4|
|....|||

所以，我们应该以一个更加合理的粒度改变$\theta$的值，其中一种方法就是本文要介绍的`最速下降法`或者叫做`梯度下降法`，它对参数的修正采用如下公式：

$$
\theta = \theta - \eta\frac{d}{d\theta}g(\theta)
$$

这个公式哪里来的？是数学家发现的！我们拿来直接用就好。关于这个公式的几个关键点：

- 这是一个减法公式，也就是如果微分$\frac{d}{d\theta}g(\theta)$的结果是正的，我们就减小$\theta$的值，反之则增加$\theta$的值，这也印证了`增减表`的描述
- 其中的$\eta$被称为学习率，它的取值决定了训练过程的收敛速度，取值越大收敛越快，但如果取值过大，也可能会出现我们刚刚描述的来回震荡无法收敛的情况。

我们把学习率设置为0.1试一下：

```python
# ps_xa_cmc/software/ai/linear-regression/06_gradient_descent.py

import numpy as np
import matplotlib.pyplot as plt


# 目标函数
def g(x):
    return (x - 1) ** 2

# 函数图像
trainX = np.arange(-1, 3, 0.01)
trainY = g(trainX)
plt.plot(trainX, trainY)


# 微分函数
def differential(x):
    return 2 * x - 2


# 梯度下降算法更新参数
def GradientDescent(theta):
    eta = 0.1  # 学习率取0.1
    return theta - eta * differential(theta)  # 梯度下降


# 瞎猜一个，并计算微分
theta = 3.0
diff = differential(theta)
cnt = 1
while diff > 1e-5:
    print('第{}轮：theta = {}, 微分值：{}'.format(cnt, theta, diff))
    plt.plot(theta, g(theta), 'o')
    theta = GradientDescent(theta)
    diff = differential(theta)
    cnt += 1

plt.show()
```

# 9 偏微分

接下来我们就采用梯度下降算法训练得到`使得我们的目标函数取值最小时对应的参数值`：

$$
E(\theta) = \frac{1}{2}\Sigma_{i=1}^n(y^i - f_\theta(x^i))^2
$$

其中：

$$
f_\theta(x) = \theta_0 + \theta_1x
$$

我们刚刚介绍梯度下降算法的时候，只有一个参数$\theta$，但现在有两个参数，怎么办？这个时候就要用到偏微分了，不要害怕，偏微分很简单，只是在计算其中一个参数的微分时把另外一个参数作为常量就行了。具体过程就不展开了，我们直接给结果，对数学特别感兴趣的可以自己去演练一下。

两个参数的更新表达式分别是：

$$
\theta_0 = \theta_0 - \eta\frac{dE}{d\theta_0} = \theta_0 - \eta \Sigma_{i=1}^{n}(f_\theta(x^i) - y^i)
$$

$$
\theta_1 = \theta_1 - \eta\frac{dE}{d\theta_1} = \theta_1 - \eta \Sigma_{i=1}^{n}(f_\theta(x^i) - y^i)x^i
$$

这就是我们上面代码的更新表达式的数学来源：

```python
# 使用更新表达式更新参数
tmpTheta0 = theta0 - ETA * np.sum(f(trainZ) - trainY)

# 参数更新后，计算误差
theta0 = tmpTheta0
theta1 = tmpTheta1
currentError = E(trainZ, trainY)
```

```python
import numpy as np
import matplotlib.pyplot as plt

# 支持中文字体
plt.rcParams['font.family'] = 'SimHei'
plt.rc('axes', unicode_minus=False)

# 随机两个参数值
theta0 = np.random.rand()
theta1 = np.random.rand()


# 我们要预测的函数
def f(x):
    return theta0 + theta1 * x


# 目标函数
def E(x, y):
    return 0.5 * np.sum((y - f(x)) ** 2)


# 读取训练数据
train = np.loadtxt('click.csv', delimiter=',', skiprows=1)
trainX = train[:, 0] # 第0列是广告费
trainY = train[:, 1] # 第1列是点击量

# 标准化
mu = trainX.mean()
sigma = trainX.std()


def standardize(x):
    return (x - mu) / sigma


trainZ = standardize(trainX)

# 几个关键参数
ETA = 1e-3 # 学习率
diff = 1 # 误差的差值
count = 0 # 更新次数
error = E(trainZ, trainY) # 误差

# 重复进行参数更新，直到误差小于0.01为止
while diff > 1e-2:
    tmpTheta0 = theta0 - ETA * np.sum(f(trainZ) - trainY)
    tmpTheta1 = theta1 - ETA * np.sum((f(trainZ) - trainY) * trainZ)

    # 参数更新后，计算误差
    theta0 = tmpTheta0
    theta1 = tmpTheta1
    currentError = E(trainZ, trainY)

    # 与上次计算结果比较
    diff = error - currentError
    error = currentError # 保存本次结果，下次计算需要与此做比较

    # 日志
    count += 1
    print('第{}次：theta0 = {:.3f}, theta1 = {:.3f}, 差值 = {:.4f}'.format(count, theta0, theta1, diff))



# 绘图确认结果
plt.plot(trainZ, trainY, 'o') # 原始的数据

# 使用我们预测出来的函数绘图
x = np.linspace(-3, 3, 100)
plt.plot(x, f(x))
plt.xlabel("广告费")
plt.ylabel("点击量")
plt.show()

```

几个关键处理：

- 定义我们的预测函数f：是一个二元一次函数
- 定义目标函数E：我们后面的训练就是让目标函数取值最小
- 定义学习率ETA为0.001
- 使用参数的更新表达式不断更新参数值，计算误差，直到误差小于0.01为止，这个时候的$\theta_0和\theta_1$就是我们最终预测结果（橙色的直线）：
